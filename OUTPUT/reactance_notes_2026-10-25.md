# РЕАКТАНС МИКРОМАГНЕТРОНА И СОГЛАСОВАННАЯ НАГРУЗКА (2026-10-25)

Рабочая точка [в корпусе]: f0 = 1 ТГц, N = 66 каверн, n* = 33 spoke-мода,
V_a = 230 В, B = 1,1 Тл, r_k = 40 мкм, r_a = 80 мкм, d = 40 мкм.
Инструмент: `OUTPUT/reactance_magnetron.py` (прогон в среде, не по памяти).

## Оси происхождения
- **[в корпусе]** — параметры из Inbox/OUTPUT (рабочая точка, Q≈700, съём 154 эВ/э);
- **[вычислено здесь]** — расчёты этого шага;
- **[внешний источник]** — стандартные формулы теории цепей СВЧ (ET0=376.73 Ом, TE10).

## 1. Адмитанс пучка на spoke-гармонике [вычислено здесь]
Lumped-оценка (аналог Ваннека/Нусиновича для бегущей волны):
G_b = 2·P_beam/V_int², P_beam = I_b·ΔW (ΔW = 154 эВ/э из pic_spoke33), V_int ≈ V_a.

| режим | I_b | P_beam | G_b |
|---|---|---|---|
| порог самозапуска | 240 мкА | 36,96 мВт | **1,397 мкСм** (−, отдача) |
| заявка корпуса | 20 мкА | 3,08 мВт | 0,116 мкСм |

## 2. Потери анодного блока [вычислено здесь]
Ёмкость ячейки C_cell = ε₀·A_cell/d = 0,34 фФ; шунтовое одной каверны
R_sh = Q/(ω₀C) = 330 кОм; 66 параллельно → R_wall = **5,01 кОм**,
G_wall = **199,7 мкСм**. Реактивность блока на 1 ТГц −7,15 Ом (ёмкостная).

## 3. Главный вывод: |G_b| ≪ G_wall [вычислено здесь]
G_b/G_wall = 0,007 — отрицательной проводимости пучка **не хватает** на потери
стенок даже при пороговом токе 240 мкА (×12 выше заявки 20 мкА). Это
независимое (цепное) подтверждение PIC-результатов П-1b/П-3: **автозапуск π/spoke
моды в этой геометрии невозможен**; рабочая конфигурация — вынужденная генерация
(injection locking, pic_lock_grid: захват фазы σ≈0,003 рад при P_inj ≥ 1 мВт).

## 4. Нагрузка: рупор = параметризованный раскрыв [в корпусе + вычислено здесь]
По замечанию автора: свободное пространство — предельный случай рупора (180°),
поэтому единая параметризация через коэффициент использования k_u:
Z_ant = η₀/k_u: k_u=1 → 376,7 Ом; 0,9 → 418,6; 0,7 → 538,2; 0,5 → 753,5 Ом.
Волновод TE10 a=300 мкм (f_c=0,5 ТГц): Z_TE = 434,9 Ом.

## 5. Согласование и КПД [вычислено здесь]
Режим вынужденной генерации (вся доступная мощность в нагрузку):
R_L,opt = 1/|G_b| = **716 кОм** (при Ib_th); β = G_L/G_wall = 0,01;
η_out = G_L/(G_L+G_wall) = **0,7 %**; P_внеш = 0,26 мВт (Ib_th), 0,021 мВт (Ib_nom).
Прямое подключение к рупору: |Γ| = 0,999, КСХ ≈ 1900 — согласующий
трансформатор обязателен; требуемый коэффициент ~sqrt(716k/377) ≈ 43,5:1
(iris/E-step или резонансная щелевая связка, как в субмм-магнетронах [внешний
источник: MSMW 2010, doi:10.1109/msmw.2010.5546139]).

## 6. Что сильно влияет на конечный КПД и режим (ответ автору)
1. **Q стенок**: η_out растёт линейно с R_sh; Q=700 из заявки даёт G_wall=200 мкСм.
   Для самовозбуждения нужно Q ≳ 10⁵ (G_wall ≤ G_b) — недостижимо при Cu-шероховатости
   (см. SCI Q4) ⇒ **режим = locking**, не автогенерация.
2. **Связь с нагрузкой**: при β≪1 почти вся мощность греет анод (2 Вт nominal-баланса
   из panel-4 viz остаются верными только при внешнем возбуждении и полном торможении).
3. **Раскрыв**: узкий рупор (k_u→0,5, Z~750 Ом) требует меньшего коэффициента
   трансформации (31:1 против 43,5:1) — практический аргумент в пользу ограниченного
   раскрытия, а не «свободного пространства».
4. **Массив ячеек**: когерентное сложение M ячеек усиливает G_b суммарно (M·G_b) —
   при M ≳ 143 самовозбуждение становится возможным (порог G_wall/G_b); это путь к
   автономному ТГц-излучателю без затравки (зафиксировать как проектировочное
   требование П-2/P-3).
