# Горячий старт: характерное время выхода на режим генерации

Дата: 2026-10-25. Артефакт расчёта: `hot_start_buildup.py` (прогон RC=0, лог ниже).
Оси происхождения: [в корпусе] — числа из OUTPUT/Inbox; [вычислено здесь] — печатает прогон.

## Постановка (по замечанию автора)
Холодный катод в этом масштабе не является тепловым ограничителем. Уточнение по
канону честности (по вопросу автора «откуда 17 мВт?»): первоисточник корпуса —
**P_cell = 2,5 Вт на ячейку** (номинал П-2: P_out 0,5 Вт / η=0,2;
mikromagneton_model_viz_notes, thermal_vacuum_notes §2). При площади элемента
150×150 мкм это **44,4 элемента/мм² и плотность 111 Вт/мм²** (1,11·10⁶ Вт/см²) —
расчётная мощность номинала. Число «~17 мВт» первоисточника в корпусе не имеет и
не воспроизводится ни одной комбинацией базовых величин; гипотеза происхождения —
перенормировка номинала на ток эмиссии: Ib_th(старт)=150 мкА против Ib_nom=10,87 мА
даёт P_element=34,5 мВт, а 20 мкА → 4,6 мВт (проверено прогоном). Для hot-start
оценки это несущественно: при любом крае (единицы–сотни мВт на элемент) нагрев
атома решётки за период (t_build/T=1400) ≈0,004 эВ ≪ kT — см. §«Тепловая инерция».
Значит реальный сценарий включения — **горячий старт**: V_a и B
подаются практически мгновенно (ps–ns коммутация), эмиссия плёночного Sc-катода
появляется сразу ([в корпусе], SCI Q1 — холодный вторично-эмиссионный катод
подтверждён литературой MSMW 2010). Вопрос сводится ко времени **нарастания
связанной моды spoke n*=33 из шума**.

## Метод
Классическая цепная модель Ван дер Поля для автогенератора (ср. Hutchinson ch.15,
Нусинович):
```
dA/dt = (A/T_dec)·(1 − A²/A_ss²),   T_dec = 2Q/ω₀
t_build = T_dec·ln(A_ss/A_noise) + T_dec·ln2
```
Числа: C_cell=0,07 фФ, R_sh=1652 кОм, G_wall=39,9 мкСм (край скрипта
reactance_correction.py; открытая сверка ×5 против f9d8357 остаётся в силе),
Q=700 [в корпусе, SCI Q4], съём 154 эВ/э [pic_spoke33], шумовая затравка kTB
при 300 K в полосе 1 ТГц. Исправление размерности по ходу работы: P[Вт]=Ib[мкА]·154·1e-6
(1 мкА·154 эВ = 154 мкВт); первая версия давала ложное «НЕЗАПУСК» во всей таблице —
ошибка поймана прогоном, зафиксирована здесь как урок канона честности.

## Тепловая инерция старта [вычислено здесь]
τ_th(зазор d) = d²/α_Cu = 14,4 нс; τ_th(планка 150 мкм) = a²/α_Cu = 203 мкс.
t_build ≤ 1,9 нс ≪ обеих постоянных ⇒ старт термически «мгновенный»: нагрев не
успевает сместить рабочую точку за время нарастания; dT≈13 К устанавливается
сотнями мкс позже и не влияет на захват режима. Это количественно подтверждает
интуицию автора («масса ничтожна»).

## Выводы
1. Горячий старт микромагнетрона: выход на режим за **~1,5–2 нс** (оптимистичный
   край V_int=4 В запускается уже с заявленных 20 мкА; консервативный край требует
   Ib≳150 мкА — снова развилка V_int, закрытие через transit-фактор сеткой).
2. Тепловая инерция элемента (203 мкс) на ≥5 порядков медленнее старта — холодный/
   горячий катод для динамики включения безразличен; вопрос холодно/горяч — только
   про ресурс и стабильность эмиссии.
3. Для массива ячеек (когерентное сложение) t_build каждой ячейки 1,5–2 нс задаёт
   темп синхронизации: задержка связи между элементами должна быть ≪ t_build или
   компенсироваться общей шиной injection locking (pic_lock_grid: σ_Δψ→0,003 рад).
4. Ограничение модели: Ван дер Поля даёт нижнюю грань (шум kTB, без конкуренции
   медленных мод — ср. отрицательный pic_grid V2/V3). Экспериментальная верификация —
   стробоскопический замер фронта импульса генерации на П-2 стенде.
