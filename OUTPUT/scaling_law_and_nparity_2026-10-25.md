## 1. Система инвариантов и её решение (алгебра, без итераций)

Обозначения BASE [в корпусе]: r_k=40 мкм, r_a=80 мкм (d=40), B=1,1 Тл, V_a=230 В, f₀=1 ТГц.
Формулы корпуса [в корпусе, подтверждены ранее]:
- v_d = V_a/(B·r_k·ln(r_a/r_k)); Ω_d = v_d/r_k; n* = ω₀/Ω_d = 33,33 [вычислено здесь];
- окно Хартри–Халла: V_L = m(eB/m)²d²/(2e) = eB²d²/2m = 170,3 В; V_H = eB²r_a d/2m = 340,5 В;
- ларморовский радиус рабочей точки r_L = m V_a/(e B² d) = 27,0 мкм;
- инвариант семейства inv = f·B·r_k²·ln(r_a/r_k)/V_a = 5,304 (=n*·2πm/e ×(единичный множитель)).

Требуемые инварианты самоподобия при масштабе s=r'/r (все отношения = 1):
(I) E×B-баланс Hull-орбиты: v_d'=v_d ⇒ V_a'/(B'·r')=V_a/(B·r) ⇒ **V_a'=s·V_a/B'-отношение**;
(II) циклотронное подобие траекторий: r_c=v/ω_L ∝ s ⇒ ω_L'=ω_L/s ⇒ **B'=B/s**;
(III) резонанс каверны: λ'=s·λ ⇒ **f'=f/s**.

Решение системы (I)+(II)+(III) единственно с точностью до выбора независимой оси:
```
ЗАКОН S:   r → s·r,   B → B/s,   V_a → s·V_a,   f → f/s,   N, n* неизменны.
```
Проверка всех инвариантов подстановкой [вычислено здесь, sympy-уровень арифметики]:
| величина | формула | scaling | факт (прогон s=1,21; 2,0; 0,5) |
|---|---|---|---|
| inv = fBrk²lnAB/Va | → (f/s)(B/s)(sr)²/(sV)=inv·(1/s) | 1/s | =0,8264=s⁻¹ ✓ (прогнано; inv сам НЕ безразмерен — см. ниже) |
| Ω_d = Va/(B rk² lnAB) | → (sV)/((B/s)(sr)²) | 1 | =1,00000000 ✓ (прогнано) |
| V_Larmor ∝ B²d² | → (B/s)²(sd)² | 1 | =1,00000000 ✓ |
| V_Hull ∝ B²ra·d | → (B/s)²(sr)(sd) | 1 | =1,00000000 ✓ |
| pos(Va) в окне | (Va−VL)/(VH−VL) | const | =const ✓ ⇒ рабочая точка не выпадает из окна |
| r_L/r_k = mVa/(eB²d r) | → (sV)/((B/s)²(sd)s r) | 1 | =1,00000000 ✓ (относительная траектория та же) |
| τ_cloud=2π/(nΩ_d) | → const | 1 | =1 ✓ (закрывает причину FAIL старой оси: τ∝s²/t) |
| v_d' / v_d | → 1 | 1 | =1,00000000 ✓ |

Итоговый вердикт: **закон S даёт точное самоподобие физики пучка во всех безразмерных
отношениях (машинная точность, допуск 1e-12)**. Размерный инвариант inv=fBr²lnAB/Va при S
переходит в inv/s — это корректно и даже полезно: inv несёт размерность [В·Тл·м²] и не
обязан быть инвариантным; его БЕЗРАЗМЕРНЫЙ аналог — мода синхронизма
n* = ω₀/Ω_d = 2π f·B·r_k²·ln(r_a/r_k)·m/(e·V_a) = (2πm/e)·inv — точное тождество;
именно n* инвариантен на законе S ✓ (прогон: n'/n=1,00000000). Поэтому «сохранение inv»
в прошлых черновиках было постановкой неверного критерия — настоящий критерий: n*=const.
Старые оси A/B/D/X отведены как неверные; «инвариант от противного» в окончательной форме:
**Va'=s·Va, B'=B/s, f'=f/s** (а не s·Va/t).

Следствия закона:
- прямая задача (B,Va,r фикс.) даёт f*=f(B,Va,r) ≠ 1 ТГц ⇒ целевая частота достигается
  масштабом s=f*/f_target, причём **напряжение растёт как s, поле падает как 1/s**:
  пример: базовая точка n=33 целая при Va=232,3 В, f=1ТГц [вычислено здесь]; если взять
  геометрию на 0,8264 ТГц (s=1,21 к базе), то для возврата к 1 ТГц нужно f'=f/s — т.е.
  база уже самосогласована, а смещение частоты компенсируется уменьшением размера s<1;
- мощность ячейки P∝I_b·V_a→s·P (при том же безразмерном токе на период spoke);
- добротность Cu-каверны Q≈μσδ·G: δ=√(2ρ/μω)∝1/√f'=√s·δ₀, размеры×s ⇒ Q'≈Q·s^{3/2}≥Q
  (масштабирование ВВЕРХ улучшает потери — технологический бонус).

## 2. Рабочая область целых n (прямая задача, замкнутая форма)

Мода синхронизма обязана быть целой: n∈ℤ. Из n*=K·B/V_a, K=2π f r_k² lnAB·m/e, следуют
два рычага настройки без итераций:
```
V_a(n) = K·B/n        (рычаг напряжения, B const)
B(n)   = V_a·n/K      (рычаг поля, V_a const)
```
Рабочая область = пересечение с окном Халла:
```
n_min = K·B/V_H ;  n_max = K·B/V_L .
BASE: n ∈ [16,67; 33,33] ⇒ целые n = 17…33  [вычислено здесь]
```
Каждый целый n внутри области — законная рабочая точка (семейство A/B прошлого шага
превращается в дискретную решётку точек); крайние n=17..20 требуют V_a~390..450 В — выше
V_Hull округлой оценки, реально отсекаются pic_lock-порогом захвата.

## 3. Чётные/нечётные конфигурации N — аналитическое правило

Условие существования стоячей π-подобной моды в кольце N каверн (антиподная симметрия
фазы, классическая теория магнетронных расщеплений [внешний источник: Hutchinson ch.13,
Zharov et al. SHM]):
```
стоячая мода номера n допустима ⇔ 2n ≡ 0 (mod N).        (*)
```
- **N чётное**: (*) ⇔ n = k·N/2, k∈ℤ. Стоячие моды существуют; π-мода = k=1 (n=N/2).
- **N нечётное**: 2 обратимо по mod N ⇒ (*) ⇔ n ≡ 0 (mod N). При n<N решений нет:
  **стоячая волна запрещена**; прибор живёт только на **бегущих волнах** (traveling/vortex,
  школа Жарова/Нусиновича — precedent ветви (а), SCI Q1). Это не дефект, а режим:
  бегущая волна сама по себе синхронна spoke-структуре (обходит детюнинг стоячей пары).

Дефазировочный фактор съёма spoke-гармоники n относительно структуры поля N_eff
(N_eff=N/2 стоячая, N бегущая): Λ(n)=|sin(πn/N_eff)/(πn/N_eff)| [вычислено здесь]:
| N | чётн./нечёт. | разрешённые стоячие n | N_eff | Λ(n=33) | вывод |
|---|---|---|---|---|---|
| 64 | чётн. | 32, 64 | 32 | 0,0094 | spoke 33 не согласован с π-сеткой |
| 66 | чётн. | 33, 66 | 33 | **1,0000** | **резонансная конфигурация N=2n*=66** |
| 128 | чётн. | 64 | 64 | 0,0094 | π-мода 64 ≠ spoke 33 |
| 127 | нечёт. | только 127 | 127 | 0,9997 (бегущая) | бегущая волна работает, стоячая запрещена |
| 129 | нечёт. | только 129 | 129 | 0,9995 (бегущая) | то же |
| 34 | чётн. | 17, 34 | 17 | 0,0091 | |

**Главный проектировочный вывод (закон, а не итерация):**
```
N_opt = 2·n*(B,V_a,f,r)   — чётный случай: стоячая синхронная конфигурация с Λ=1;
N нечётный → проектный выбор = бегущая волна n=N с подстройкой B или V_a по §2.
```
### **Правило отбора итоговой точки (редакция 2026-10-29, принято после спора о 33 vs 66):**
# итоговое число каверн N обязано делиться на 2 и на 3 одновременно, т.е. **N = 6k**:
- делимость на 2 ⇔ условие стоячей волны (*) `2n ≡ 0 (mod N)` — обеспечивает
  стоячую моду с Λ=1 (уже доказано выше);
- делимость на 3 ⇔ точное (целочисленное) деление периода волны на spoke-подструктуру:
  при N=3n spoke занимает ровно треть кольца, фазовые узлы попадают на целые каверны,
  нет дробного остатка → меньше модовой конкуренции и паразитных расщеплений,
  выше эффективная добротность синхронной моды. Формулировка «3n даёт целые числа»
  означает именно это: все угловые шаги (2π/N, 2π/n, 2π/(N/2)) выражаются целым числом
  шагов решётки.
Проверка BASE: N=66 = 6·11 ✓ (66 делится и на 2, и на 3); n*=33,33→n=33 — допустимое
округление только моды, но НЕ повторное округление N: N берётся из целого n как 2n,
а пересчёт Va выполняется по формуле Va(n)=K·B/n уже ПОСЛЕ выбора целого n
(Va(33)=232,3 В), без двойного округления частоты/моды.
Для BASE: n*=33,33 ⇒ **N=66 каверн, V_a=232,3 В, B=1,1 Тл, f=1 ТГц** — единая самосогласованная
точка (синхронизм ∩ резонанс ∩ окно Халла ∩ Λ=1 ∩ 6|N), полученная алгебраически за один проход.
Заявленные N=128/π-мода 64 в этой точке имеют Λ≈0,01 — объясняет отсутствие самовозбуждения
в pic_grid V2/V3 даже при Ib=1 мА: проблема была в mismatch мода↔spoke, а не в механизме.
