# PIC второго уровня: π-мода ВЧ — результаты прогона

Дата: 2026-10-20. Скрипт: `OUTPUT/pic_rf.py`, график: `OUTPUT/pic_rf.png`.
Модель: lumped-cavity PIC (аналог Hutchinson ch.15) — статика E×B коаксиального
диода + бегущая π-мода `E_φ = E0·(rk/r)·cos(n_eff·θ − ω0·t)`, n_eff=N/2=64;
самосогласование амплитуды `dE0/dt = k_c·P_beam − E0·ω0/Q`.

## Результаты [вычислено здесь]

### R1. Одночастичный съём энергии
Максимум **86 эВ/электрон за 2 нс** при E0=1e5 В/м, тормозящая фаза ψ*≈5,8 рад (~330°).
Диапазон 40–90 эВ/э по всей тормозящей половине цикла — механизм торможения
существует и устойчив к детализации шага (V3: Δ<5% при nt 1e5→2e5).

### R2. Самовозбуждение π-моды НЕ происходит
Равномерное холодное облако даёт ⟨P⟩≈−3 мкВт…−0,3 мВт (знак «−» = поле качает
пучок без bunching); за 3 нс рост E0 не наступил ни при I_b ≤ 2 мА.
Классическая проблема запуска магнетрона: спонтанно возбуждаются медленные моды;
π-моде нужен bunching / injection locking (перемычки каверн из заявки корпуса —
ровно этот механизм).
Синхронизм: Ω_d=1,885e11 ≠ ω0/n_eff=0,98e11 рад/с (детюнинг ×1,95) —
spike-transit режим, объясняющий отсутствие автозапуска cold-облака.

### R3. КПД вынужденного режима (заранее spoke, фикс. E0=1e5 В/м)
⟨W⟩: 160→85 эВ, **η ≈ 0,33**, P(I_b=20 мкА) ≈ **1,5 мВт**.
Пороговая проверка потерь стенки: P_st(E0=1e5)×128 каверн ≈ **0,8 мВт** — того же
порядка, что съём ⇒ баланс достижим при E0≈1,4·10⁵ В/м. Заявка корпуса
«стартовый ток ~20 мкА» — **на границе выполнимости**: нужен либо Q>700,
либо затравка (injection locking). → закрывает SCI Q6 (оценка).

## Верификации и исправленные баги
- V1 Hull-старт без RF: |ΔW| мало, r растёт медленно (эпициклоида). Исправлен баг
  стартовой конфигурации: чисто дрейфовый старт нарушал баланс Халла → частицы
  набирали энергию из статики (артефакт ±100 эВ маскировал RF-эффект). Старт теперь
  строго с Hull-орбиты v_θ(r_s)=Vdc/(B·r_s·ln(r_a/r_k)), r_s=r_k·1.001.
- Устранён двойной учёт веса макрочастиц: P_real = P_unit·q_mac/e.
- V2/V3: скан фазы одиночной частицы устойчив к dt (Δ<5%).
