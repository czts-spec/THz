## 4. Замечания и узкие места (для следующей итерации)

1а. **Циклотронная спираль vs зазор.** При 200 В и B = 1,1 Тл полный перпендикулярный радиус r_c = 43,4 мкм превышает зазор 40 мкм; спираль с типичным для магнетрона углом впрыска (v_perp ≈ v·sin60°) даёт 37,5 мкм — влезает впритык. Концепт молчит об угле впрыска и о том, что электронное облако удерживается внутри зазора до набора энергии. Для П-0 нужен PIC-прогон траекторий в скрещённых полях конечной геометрии. [в корпусе — пробел; вычислено здесь]
1б. **Окно Хартри–Халла.** Заявленное V_a = 195–370 В — из аналитической модели; численное значение критического поля разделений (critical field) в документах не приведено. Для П-0 полезно вынести формулу окна отдельным расчётом. [в корпусе — пробел]
2. **Добротность Q≈700 при Bosch-гребешке 80 нм** увязана с гашением шероховатости на этапе A6 (гальваника+CMP); контроль-точка не измерена — подлежит замеру на П-0. [в корпусе]
3. **Аспект травления 37:1** — «на пределе», допущено двухэтапное; риск назван, контрмера есть. [в корпусе]
4. **Монография (ТЕРАГЕРЦОВІ ТЕХНОЛОГІї.md)** — объёмный референс 5759 строк; полнотекстовый поиск по ней ещё не выполнялся (область, шаг, покрытие не замерялись) — любые ссылки на неё ниже помечать осью происхождения и параметрами поиска, по канону «отрицательного ответа».
5. **Исправление FSO** корректно заменяет пункт сравнения в weather-документе; противоречий между документами серии не обнаружено.

## 5. Формулы проверки (воспроизводимость)

- v_φ = 2πf·r_a/n, n = N/2 = 64 (π-мода): 2π·1e12·80e-6/64 = 7,85e6 м/с = 0,0262c
- r_c = m·v_perp/(e·B), v = √(2eU/m): U=200 В → v=8,4e6 м/с (0,028c, релятивистская поправка γ=1,0004 — ничтожна); B=1,1 Тл → полный r_c = 43,4 мкм; при v_perp = v·sin60° → 37,5 мкм
- f_c = eB/2πm = 30,8 ГГц при 1,1 Тл
- δ = √(2ρ/ωμ₀), ρ_Cu=1,7e-8 → δ=65,8 нм на 1 ТГц
- J_CL = (4ε₀/9)·√(2e/m)·V^{3/2}/d² = 577 А/см² при 250 В, 40 мкм (проверено численным прогоном здесь)
- G_решётки ≤ 4πA/λ² (апертурный предел); элементная сумма N при шаге λ/2 совпадает с ним — оговорка в flow-документе верна.
