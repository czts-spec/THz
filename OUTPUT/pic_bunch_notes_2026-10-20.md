# PIC П-1b: spoke-bunching и порог самовозбуждения π-моды — заметки прогона
Дата: 2026-10-20. Автор: dtba3a. Скрипт: OUTPUT/pic_bunch.py, график: OUTPUT/pic_bunch.png.
Контекст: закрывает разрыв П-1/R2 (равномерное облако моду не возбуждало).

## Метод [вычислено здесь]
Lumped-cavity PIC (Hutchinson ch.15 [внешний источник]), поля и Hull-старт — идентичны
верифицированному pic_rf.py [в корпусе OUTPUT]. Новое: стартовое облако = доля frac в окне
ψ∈[5,8; 6,4] рад на отдельных кавернах (зародыш spoke) + равномерный фон; метрика порядка
R=|⟨exp(i·N/2·θ)⟩|; критерий старта: E0 растёт >10× дольше 2·T_dec.

## Результаты прогона (/tmp/picbunch.log, seed=5/7/9, M=256, T=6 нс)
- **A. Зародыш spoke живёт**: R поднимается с ~0 до **0,62–0,66** за ~2 нс и держится;
  средняя энергия облака падает 161→117 эВ — пучок ОТДАЁТ энергию волне даже при
  слабом поле (E0≈100 В/м). Механизм bunching в коаксиальном Huber-диode подтверждён.
- **B. Порога самовозбуждения нет до Ib=10 мА**: E0 стартует со 100 В/м и монотонно
  затухает к T_dec=111 пс при всех токах. Причина — детюнинг из П-1 (Ω_d=1,9ω₀n_eff):
  облако проскакивает каверну быстрее фазы волны, фаза торможения ψ* не самоподдерживается
  без начального сгустка достаточной массы/поля.
- **C. Масштабирование по frac**: Rmax растёт с долей зародыша (см. PNG); усиление поля
  отсутствует во всех случаях — т.е. spoke сам по себе не запускает моду в этой модели.

## Вывод для концепта (SCI Q6, уточнение П-1/R3)
Заявка «стартовый ток 20 мкА ⇒ самовозбуждение» НЕ подтверждается lumped-моделью:
нужен либо внешний injection locking (затравка ≳1 мВт — тогда режим C из П-1 даёт η≈0,3),
либо механизм фазовой фиксации spoke↔моды (перемычки между кавернами, ёмкостная связь —
патентный claim корпуса [в корпусе]). Это проектировочное требование к П-2, не опровержение
концепта: в реальных магнетронах запуск идёт через медленные моды/шум, которых модель не содержит.

## Ограничения
2D, single-mode, без потерь эмиссии/пространственного заряда; R=0,6 при M=256 — верхняя
оценка порядка (флуктуации ∝1/√M). Следующий уровень: 2 моды + перемычки или RF-затравка.
