## Постановка: три ветви как система уравнений

Неизвестные: V_a, B, число spoke-сгустков n, мощность инжекции P_inj. Фиксированы: f0 = 1 ТГц, r_k = 40 мкм, r_a = 80 мкм, N = 128, Q = 700.

- **(а) синхронизм:** n* = ω0/Ω_d, Ω_d = v_d/r_k, v_d = V_a/(B·r_k·ln(r_a/r_k)) ⇒ **V_a = ω0·B·r_k²·lnA/n***
- **(б) спайк:** сгусток в тормозящей дуге ψ ∈ [π, 2π] + малость дефазировки за пролёт |Φ_tr| < π/2, Φ_tr = (ω0 − n·Ω_d)·τ_tr, τ_tr = π/n/Ω_d
- **(в) locking (Адлер):** |Δ| ≤ Ω_A·√(P_inj/P_st), Ω_A = ω0/(2Q)

Ключевое алгебраическое наблюдение: подстановка (а) в Φ_tr даёт Φ_tr(n=n*) ≡ 0 — синхронный spoke автоматически удовлетворяет условию (б) по усреднению поля; торможение задаётся фазовым сдвигом ψ (pic_rf R1: ψ*≈5,8 рад ∈ [π,2π] ✓). Ветви НЕ конкурируют — они дополняют друг друга.

## Числовое решение системы

**Рабочая точка (единственная с точностью ±1 мода):**
```
B  = 1,1 Тл;  V_a = 230 В;  f0 = 1 ТГц
n* = ω0/Ω_d = 33,3  → spoke из 33 сгустков
     угловой шаг 2π/33 = 0,190 рад; линейный на аноде 15,23 мкм
```

Проверки:
1. **(а)⇄окно Халла:** V_a(синхр, n*=33, 1,1 Тл) = 232,3 В — совпадает с корпусным 230 В с точностью ~1%; внутри окна [195;~370] В. Для π-моды n=64: 119,8 В < 170 В (порог запуска) — точка (а) для π-моды АНАЛИТИЧЕСКИ мертва.
2. **(б):** окно устойчивости по n ∈ [23; 64] при V_a=230 В — n*=33 лежит глубоко внутри. Отрицательный результат pic_grid V1/V4 объясняется стартом равномерного облака без spoke-структуры (нет ψ∈[π,2π]), а не отсутствием механизма.
3. **(в):** детюнинг π-моды Δ/2π = 920 ГГц ⇒ P_inj ≥ P_st·(Δ/Ω_A)² ≈ 10 кВт — невыполнимо. Для согласованной моды n*=33: Δ/2π = 9,8 ГГц — покрывается MEMS-подстройкой ±23 ГГц (запас ×2,3) БЕЗ внешней инжекции; роль (в) сводится к удержанию настройки и фазовой стабилизации (затравка ≳ P_st ≈ 6 мВт/каверну достаточна после юстировки). Самозапуск определяется порогом тока эмиссии (поле Buneman-порога E_th ~ ω0·m·r_k/e ≪ рабочих) — PIC со spoke n=33 даст I_b,th (следующий шаг, SCI Q6).

## Ревизия корпусных формулировок (предложения автору)

1. «π-мода N/2 = 64» → **«сповая мода синхронизма n* = ω0/Ω_d ≈ 33»**. Каверны: 66 (=2·33, субгармоническое согласование) или оставить 64 с проверкой симметрии чётной решётки/нечётного spoke отдельным прогоном.
2. «Десятки оборотов на период волны»: ларморовских оборотов ЭЛЕКТРОНА за T0 = f_c/f0 = 0,031 (доли!). «Десятки» корректно относятся к числу сгустков spoke n*≈33. Формулировку уточнить.
3. Совпадение V_a(синхр)=232 В с корпусным 230 В при n*=33 указывает: концепт интуитивно выбрал верную рабочую точку, но описал её модную структуру как π-моду.

## Итог

Система (а)+(б)+(в) разрешима; все три ветви выживают, объединяясь в единую точку (230 В, 1,1 Тл, n*≈33). Ни одна ветвь не отвергнута. Числа воспроизводятся прогоном скрипта (вывод детерминирован).
