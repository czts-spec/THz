## Назначение

Дом (рабочее пристанище) агента-среды `Qwen` внутри проекта THz.
Здесь живут конфигурация среды, зеркала, служебные скрипты и локальные артефакты, которые не должны размываться по корню репозитория.

Этот каталог является Qwen-домом проекта и дополняет профильный `chatman`-канон, хранящийся в `.chatman/`.

## Состав

| Путь | Что это |

| `bin/` | Qwen-специфичные служебные инструменты и скрипты среды |
| `sync.sh` | Скрипт обновления зеркала |
| `README.md` | Этот файл |
| `CLAUDE.md` | Локальное правило дома для Qwen; исторические Claude/AIAΣA упоминания не являются действующей инструкцией |

## Правила дома

1. `ENV/Qwen/` — основной локальный дом Qwen для этого проекта.
2. Корневой канон и профильные правила лежат в `.chatman/` и в `czts-spec/dtba3a-del`.
3. Claude / AIAΣA внутри этого дома — историческая привязка, не рабочий modus operandi проекта.
4. Рабочие действия оформляются в репозитории, а не в памяти; изменения в среде сопровождаются проверяемыми артефактами.
5. Состояние среды живёт локально; репозиторий хранит только те данные, которые должны быть в git.

## Резервное зеркало workspace

Зеркало — побайтовая копия каталога `.git` рабочего пространства `/workspace`
(голый снимок objects/refs/index, восстановим через `git clone mirror/workspace.git`).

Обновление зеркала:

```bash
./ENV/Qwen/sync.sh
```

Проверка целостности зеркала (все объекты читаются):

```bash
git -C ENV/Qwen/mirror/workspace.git fsck --no-progress
```
